# 饼控自律 · 使用说明书

深夜烘焙店主题的个人效率工具：任务管理 + 番茄钟。
专注 = 烤饼干，一个番茄出炉一块 🍪

## 我有两个版本

| | 浏览器版（PWA） | 桌面悬浮窗版 |
|---|---|---|
| **是什么** | 完整功能的主应用 | 屏幕右上角的小计时条 |
| **适合** | 手机、平板、电脑浏览器里用 | 电脑办公时盯着倒计时 |
| **数据** | 存在浏览器的 localStorage | 存在悬浮窗自己的本地存储 |
| **注意** | 换浏览器/清缓存会丢数据 | 两边数据**不互通** |

## 一、浏览器版怎么打开

**方式 1（推荐，手机也能用）**
浏览器打开：
```
https://bl026732-ship-it.github.io/bingkong-pwa/
```
打开后可以"安装到主屏幕/桌面"（浏览器菜单里选"安装应用"），之后像 App 一样全屏使用，断网也能开。

**方式 2（本地开发版）**
```
node server.js
```
然后浏览器打开 http://localhost:8520
（改动代码后刷新页面即可看到效果）

## 二、桌面悬浮窗怎么打开

**已经安装过**：开始菜单搜 "BingkongPip" 启动。

**还没安装**（第一次用）：双击这个安装包，装完就在开始菜单里了：
```
src-tauri\target\release\bundle\nsis\BingkongPip_0.1.0_x64-setup.exe
```

**临时用一下不安装**：直接双击运行
```
src-tauri\target\release\app.exe
```

### 悬浮窗操作速查

| 想干什么 | 怎么做 |
|---|---|
| 移动位置 | 按住**时间数字**拖动 |
| 输入当前任务 | 点击上方灰色小字 |
| 暂停 / 继续 | 鼠标悬停窗口，点 ⏸ / ▶ |
| 重置 / 关闭 | 悬停窗口，点 ↺ / ✕ |
| 关机后再打开 | 自动恢复上次倒计时 |

## 三、主应用功能速查

- **三个任务池**（顶部切换）：
  - 🍪 今日待烤 —— 今天要做的，点击任务即开始专注
  - ⏰ 基础池 —— 紧急的事（如备考），hover 任务点 → 转入今日
  - ✦ 卓越池 —— 重要不紧急的事（读书、学技能）
- **饼干进度**：每个任务可设目标饼干数（± 按钮调整），完成一个番茄点亮一格
- **固定 25 分钟**：专注 25 分钟 → 自动休息 5 分钟
- **主题**：右上角 ◐ 切换深色/浅色
- **悬浮窗（浏览器内）**：顶栏"⿻ 悬浮窗"（需 Chrome/Edge）

## 四、数据存在哪

所有数据只存在**本机**，没有账号、没有云端：

- 浏览器版：所在浏览器的 localStorage（F12 → 应用 → 本地存储 可以看到）
- 悬浮窗版：Windows 用户目录下的应用数据文件夹

**重要**：清浏览器缓存 / 卸载应用 = 数据清空。重要数据请用任务池定期回顾，或截图备份。

## 五、继续开发（对 AI 助手说）

本项目用 Kimi Code CLI 开发，在本文件夹里运行：

```
kimi --continue
```

常用维护命令：
```
node server.js        # 本地预览（端口 8520）
npx tauri build       # 重新打包桌面安装包（输出在 src-tauri\target\release\bundle\nsis\）
git push              # 推送到 GitHub，线上版 1~2 分钟后更新
```

推送后线上 PWA 第一次打开可能还是旧版（Service Worker 缓存），**刷新一次**即可。
